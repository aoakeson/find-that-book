# ADR 0002: .NET 10 LTS instead of .NET 8

Status: accepted (2026-10-24)

## Context
The brief says ".NET 8 Web API". .NET 8 reaches end of support on 2026-11-10, about two weeks after this submission.
.NET 10 is the current LTS (support to 2028-11-14).

## Decision
Target `net10.0`. `global.json` pins SDK `10.0.100` with `rollForward: latestFeature`, so any 10.0.1xx–10.0.4xx SDK
builds it, and opts `dotnet test` into Microsoft.Testing.Platform (required by xUnit v3 on the .NET 10 SDK).

## Consequences
- We can use .NET 10 features the design relies on: built-in minimal-API validation (`AddValidation`), OpenAPI 3.1
  generation, `HybridCache`, `System.Threading.Lock`.
- A reviewer needs the .NET 10 SDK (official installer, winget, Homebrew, or the preview `dotnetup` tool; see README).
