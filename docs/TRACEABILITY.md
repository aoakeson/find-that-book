# Traceability

Each requirement of the InfoTrack "Find That Book" brief, the code that meets it, the tests that prove it and the
evaluation runs that measure it. Edge cases (IN-, DA-, AI-, SY-, DE-, TR-, R3-, BT- IDs) are tracked one by one in
[FINDINGS-STATUS.md](FINDINGS-STATUS.md). Paths are relative to the repository root; test names are `Class.Method`;
run folders are under `eval/results/` and indexed in `eval/RESULTS.md`. All runs below are on the final build (source
`918d7b88`, pipeline binaries `bb794a4f`) unless marked. Golden and hard are in-sample (used while the rules were tuned);
only the sealed held-out set (409 queries, run once) speaks to generalization.

**Tests on the final source:** `dotnet test` ran 3,100 tests: 3,095 passed, 0 failed, 5 skipped (opt-in live checks).
